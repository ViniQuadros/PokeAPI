
# Poke API

A full-stack Pokémon website that combines a JavaScript frontend with a Spring Boot backend to interact with Pokémon data through API requests. The project explores different ways of consuming and presenting Pokémon information across multiple pages, with user authentication and database integration.

## Build with
- HTML
- CSS
- JavaScript
- Spring Boot
- Neon Database

## Features

- Login authentication
- Multiple pages
- API requests

## Run

Clone the project

```bash
git clone https://github.com/ViniQuadros/PokeAPI
```

Go to the project directory

```bash
  cd SnakeGame/
```

Run the application
Maven (Windows and Linux):
```bash
  ./mvnw spring-boot:run 
```
